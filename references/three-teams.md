# 智囊团三队职责与总协调（skill 版速查）

> 来源：vertciti《智囊团章程》正本 `~/workspace/vertcity/org/think-tank.md`（2026-09-25 生效，D259 升级临时董事会）。
> 本文件是 skill 执行时的速查摘要，权威口径以章程正本为准。

## 红队：质疑者 / 风险视角

- **干什么**：专挑逻辑漏洞和事实硬伤。扮最严的尽调投资人：这个决策要是错的，错在哪、代价多大。
- **权限**：不只挑逻辑，也核查事实依据——引用事实必须有出处，虚构/夸大直接判死刑。
- **输出义务**：每条质疑必须可证伪（说清"什么证据出现时我这条质疑作废"）。
- **禁区**：不许只说"有风险"不给风险量级；不许人身攻击式质疑。

## 蓝队：价值 / Miao 视角

- **干什么**：站 Miao 本人一边。只算一笔账：对他的人生是赚是赔——时间、钱、风险敞口、机会成本、注意力消耗。
- **标尺**：N=1——不服务抽象的"公司增长"，服务"运营 Miao 的人生"这个唯一主题。
- **输出义务**：每个"接"必须回答"他为此付出的最小代价是什么"；每个"驳"必须回答"驳掉后他失去了什么"。

## 白队：工程 / 执行视角

- **干什么**：可行性、成本、排序、依赖、前置条件、平台限制。不谈愿景，只谈怎么落地。
- **输出义务**：任何"接"必须附带执行链（谁做/几步/前置依赖/验收标准）；任何"改"必须说明改后执行链变在哪。
- **诚实线**：做不到就说做不到，不许用"理论上可行"代替排期承诺。

## 总协调人

- **干什么**：组织辩论、综合裁决。不下场站队，只负责：议题发布与硬约束、三队独立初稿的隔离、主持辩证轮次、输出裁决书。
- **裁决方法**：麦肯锡工作法五条——
  1. **假设驱动**：先写核心假设，再列验证证据，最后给结论。不许先堆材料再找结论。
  2. **MECE**：选项相互独立、完全穷尽；有"其他"项必须说明为什么不展开。
  3. **金字塔表达**：裁决书第一段就是结论，下面才是论据。
  4. **数字先行**：涉定价/成本/规模必须有数字口径，不许用"大幅""显著"代替数字。
  5. **反方必答**：红队质疑逐条回应，不许跳过。
- **快审模式**（D478 precedent）：时间敏感＋可逆/低风险事项，总协调可 inline 戴红/蓝/白三顶帽子 4h 内出裁决，但裁决书必须书面记录"红队最强反对意见＋为何驳回"，且不豁免门禁 0 与不得代裁四条。

## 不得代裁四条（总协调直接判"不进辩论"）

1. 董事长硬保留事项（花钱付款、身份验证/签名、以 Miao 名义发送消息、DNS 修改）。
2. GC 一票否决事项（合规红线）。
3. 重大战略转向与组织编制变更。
4. 对外法律承诺。

以上走原流程（CEO/董事长通道），智囊团不裁。

## 意外视角（每议题至少一位，轮换）

从议题领域之外抓视角，候选池（按议题选其一）：
- **监管者/平台方视角**：这件事在平台规则/法律下看是什么形状。
- **被影响的第三方视角**：决策的外部性落到谁头上。
- **未来的自己视角**：6 个月后回看，这个决定经得起吗。
- **对手视角**：竞争者/质疑者会怎么利用这个决定。

作用：打破红/蓝/白三队的共同盲区。意外视角同样遵守回应纪律和一句话压缩。
